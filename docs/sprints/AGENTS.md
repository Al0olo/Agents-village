# Agent instructions: sprints

**Scope:** `docs/sprints/`. Sprint intent: goals, tickets, gates.

Change a sprint file only when the plan changes, and explain why in the PR and the handoff log. Ticket ids are stable once published; add new tickets at the next free number rather than renumbering. Keep every ticket at 8 points or less, with dependencies and a testable outcome. State lives in `docs/implementation/`. See the `sprint-workflow` skill. Root rules in [AGENTS.md](/AGENTS.md) apply.
