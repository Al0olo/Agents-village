# Agent instructions: adr

**Scope:** `docs/adr/`. Architecture decision records.

Write an ADR for any decision that is hard to reverse or that other work depends on. Copy the template, take the next number, set the status, add it to the index in `README.md`. Never rewrite an accepted ADR; supersede it with a new one and update the old status line. Root rules in [AGENTS.md](/AGENTS.md) apply.
