# Security policy

Agent Village runs language-model agents that can hold credit balances and, in later
milestones, reach the outside world. Please report vulnerabilities privately through
GitHub's *Report a vulnerability* (private security advisory) on this repository.

Areas of particular interest: memory poisoning and prompt injection that bypass the
admission policy, forged authority or payment requests, escapes from the capability
checks, and anything that lets a citizen act outside its spend caps.
